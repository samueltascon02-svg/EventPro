# Evento Pro

## Descripción

Evento Pro es un sistema web para la gestión de eventos y espectáculos. La plataforma permitirá administrar eventos, usuarios, lugares, entradas y reservas, facilitando la organización y participación en diferentes tipos de eventos.

## Objetivo general

Desarrollar un sistema web que permita gestionar de manera organizada eventos y espectáculos, facilitando a los organizadores la administración de eventos, lugares, entradas y reservas, y permitiendo a los usuarios consultar y participar en los eventos disponibles.
